# 농막/동지집 센서 → 구글시트

Xiaomi **LYWSD03MMC** 온습도계 3개의 **시간별 최고/최저 온·습도 이력**을 BLE로 받아
구글시트 **「동지집 기온·습도 기록」**에 **증분 기록**한다.
Mi Home 앱의 월별 그래프를 캡처해 수기 입력하던 작업을 대체한다.

두 가지 사용 경로:
- **폰(안드로이드 크롬)** — 방문 시 손으로 (Web Bluetooth)
- **PC(파이썬)** — 명령 하나로 전자동 (`farmhut_sync.py`)

## 파일

| 파일 | 역할 | 어디서 실행 |
|---|---|---|
| `index.html` | 폰 웹앱 (Web Bluetooth) | **GitHub Pages**로 서빙 → 안드로이드 크롬에서 열기 |
| `Code.gs` | Apps Script 서버 (업로드 수신·중복제거·요약) | **구글시트 Apps Script**에 붙여 웹앱 배포 (GitHub에선 실행 안 됨, 백업용) |
| `farmhut_sync.py` | PC 전자동 동기화 | 센서 근처 **PC에서 `python`** |
| `README.md` | 이 문서 | — |

## 센서 ↔ 위치 ↔ MAC 끝자리

| 위치 | MAC | 끝자리 |
|---|---|---|
| 내부1층 | `A4:C1:38:6A:77:BE` | BE |
| 바닥외부 | `A4:C1:38:B4:5E:13` | 13 |
| 다락(휴대) | `A4:C1:38:32:8C:21` | 21 |

## 구글시트 탭

- **농막_시간별** — 원자료: `시각 · 센서 · 최고온도 · 최저온도 · 최고습도 · 최저습도 · 센서idx · 업로드시각`
- **농막_그래프** — QUERY 피벗 + 라인차트(센서별 일별 최고 온도/습도). 원자료 쌓이면 자동 갱신. 온도축 −20~40℃ 고정.

## 동작 원리 (요약)

- 서비스 `ebe0ccb0-…`, 이력 notify `ebe0ccbc-…`, 시작 인덱스 포인터 `ebe0ccba-…`(seek), 현재값 `ebe0ccc1-…`.
- 이력 레코드 14바이트: `idx(u32) · ts(u32, 부팅후초) · 최고온도(i16/10) · 최고습도(u8) · 최저온도(i16/10) · 최저습도(u8)`.
- 기기 시계가 실제 시각이 아니라, 연결 시점의 카운터+현재시각으로 **절대시각 환산**.
- **증분**: 시트의 해당 센서 마지막 시각 이후 인덱스부터만 받음(`ebe0ccba` seek). 폰/PC/상태가 바뀌어도 시트 기준.
- **중복제거**: 서버(Apps Script)에서 `(센서, 정시)` 기준. 겹쳐 받아도 중복 행 안 생김.

## 설치 / 배포

### 1) Apps Script (서버)
1. 시트 → **확장 프로그램 ▸ Apps Script** → `Code.gs` 붙여넣기
2. 상단 `var SECRET = 'CHANGE-ME';` 를 원하는 값으로 변경
3. **배포 ▸ 새 배포 ▸ 웹 앱** (실행: 나 / 액세스: 모든 사용자) → `…/exec` URL 확보
   - 코드 수정 후엔 **배포 관리 ▸ 새 버전**으로 재배포해야 반영됨
4. 확인: `/exec` 를 브라우저로 열면 `{"ok":true,…}` JSON

### 2) GitHub Pages (폰 앱)
1. 리포에 `index.html` 업로드(루트)
2. **Settings ▸ Pages ▸ Deploy from a branch ▸ main /(root)**
3. `https://<아이디>.github.io/<repo>/` 를 안드로이드 크롬에서 열기

### 3) 폰 사용
1. ① 설정에 `/exec` URL + SECRET 입력
2. **Mi Home 완전 종료**
3. 위치 버튼(**내부1층·BE / 바닥외부·13 / 다락·21**) 또는 **[전체 차례로]** → 선택창에서 **안내된 끝자리** 기기 선택 → 자동 업로드

### 4) PC 사용 (전자동)
```bash
python -m pip install bleak
set FARMHUT_SECRET=당신의시크릿값      # Windows (PowerShell: $env:FARMHUT_SECRET="...")
python farmhut_sync.py                 # 세 센서 모두 증분 업로드
python farmhut_sync.py --dry-run       # 업로드 없이 미리보기
```
MAC 으로 직접 찾으므로 선택창/LCD 대조 없이 완전 자동. Mi Home 은 종료.

## 보안

- **실제 SECRET 은 커밋 금지.** 커밋된 파일은 `CHANGE-ME` 플레이스홀더. PC는 환경변수 `FARMHUT_SECRET` 로 주입.
- `farmhut_sync.py` 의 `WEBAPP_URL` 은 공개됨 — 쓰기는 SECRET 로 보호되고 doGet 은 요약(행수·마지막시각)만 노출하므로 위험 낮음. 숨기려면 비공개 리포 사용.
- `index.html` 자체엔 비밀 없음(URL·시크릿은 사용 시 입력, 브라우저에만 저장).

## 알려진 제약 / 참고

- **iOS(아이폰/아이패드) Web Bluetooth 미지원** → 안드로이드 크롬(또는 데스크톱 크롬) 사용.
- 센서 저장: **시간당 1개**, 실측상 **~5개월+ 보관**(가득 차면 가장 오래된 것부터 덮어쓰는 링버퍼). 월 1회 동기화도 데이터 손실 없음.
- 용량: 3센서 시간당 = 연 약 2.6만 행. 시트 한계 1천만 셀(수십 년 여유). 쾌적 체감은 수만 행 수준.

## 개발 메모

- 샤오미 순정(stock) 펌웨어 기준. 이력 프로토콜은 공식 문서 없는 리버스엔지니어링.
- `ebe0ccba` 에 시작 인덱스를 write 하면 `ebe0ccbc` 가 그 지점부터 스트림(비파괴적) — 실기기로 검증됨.
