# 「동지집 기온·습도 기록」 시트 정리 설계 (2026-11-16, 설계안)

> 목표: 사람은 **탭 4~5개만** 보고, 기계가 쓰는 탭은 숨긴다. 보는 탭은 모양·색·단위·제목 규칙을 하나로 맞춘다.
> 원칙: **기계 탭의 이름·위치(열)는 바꾸지 않는다**(Code.gs·Pi가 이름으로 찾음). 숨기기·순서 바꾸기·차트 옮기기만 한다.

## 1. 지금 상태 (탭 21개)

| 분류 | 탭 | 누가 쓰나 | 사람이 보나 |
|---|---|---|---|
| 원자료(기계) | 농막_현재(1~9행), 농막_시간별, 농막_평균, 농막_배터리, 농막_시간요약, 재실기록 | Pi → Code.gs | 거의 안 봄 |
| 원자료(기계) | 부여_시간별, 부여_일별, 동지집_예보(A~G), 중기예보, 예보검증(A~C) | Pi(kma_sync) → Code.gs | 거의 안 봄 |
| 계산(수식) | 비교, 농막_일별, 농막_센서, 최근5일_시간별(표) | 수식 | 안 봄(그래프 원본) |
| 보기 | 농막_현재 10~68행(대시보드), 최근5일_시간별(차트 2), 그래프(차트 6), 농막_그래프(차트 2), 동지집_예보(차트 1), 예보검증(차트 1) | 수식 | **봄 — 6곳에 흩어짐** |
| 입력 | 명령 | 사람(+Pi 결과) | 봄 |
| 관리 | 안내(웹앱 주소 등), 농막_기기(IP·MAC) | 사람·Code.gs(A14) | 가끔 |

**문제**
1. 보는 내용이 6개 탭에 흩어져 있고, 그중 4개는 기계 탭 안에 섞여 있다(대시보드가 `농막_현재` 10행부터, 예보 차트가 `동지집_예보` 옆).
2. 그래프 색이 탭마다 다르다(`그래프`·`최근5일`은 관측소 파랑·바닥외부 초록·1층 빨강·다락 보라인데, `농막_그래프`는 기본색).
3. 제목·날짜 형식이 제각각이다("최고기온 (°C)", "최근 5일 시간별 온도 (°C) · …", 날짜 `11/16(월) 08시` / `2026-11-16` / `2026. 9. 6`).
4. 히터 전력·가동(`농막_시간요약`)은 데이터는 있는데 보는 그래프가 없다.

## 2. 새 구조 (보는 탭 5개 + 숨긴 탭)

맨 앞부터 이 순서로 둔다. 휴대폰 시트 앱은 탭 이름이 잘리므로 **이모지 + 두세 글자**로 짓는다.

| 순서 | 탭(새 이름) | 내용 | 출처 |
|---|---|---|---|
| 1 | **🏠 지금** | 지금 대시보드(①지금 ②오늘 밤 ③3일 ④4~10일 ⑤농막 상태 ⑥해 ⑦할 일) | `농막_현재` 10~68행을 옮김(§4) |
| 2 | **📈 5일** | 온도·습도 최근 5일(시간별) 차트 2개, 표 없음 | `최근5일_시간별` 차트를 옮김 |
| 3 | **🔥 난방** | (새로) 날마다 히터 kWh·가동 시간, 실내(1층·다락)와 바깥 평균, 최근 7일 시간별 kWh | `농막_시간요약` |
| 4 | **📅 계절** | 일별 최고·최저·평균기온, 습도(관측소·바깥·1층·다락 비교) | `그래프` 6개 + `농막_그래프` 2개를 모아 같은 색으로 |
| 5 | **🌦 예보** | 예보 vs 실측, 예보 검증 차트 | `동지집_예보`·`예보검증` 차트를 옮김 |
| 6 | **✍ 명령** | 명령 입력(지금 그대로) | `명령` (이름 유지) |
| — | 숨김: 원자료 11개 + 계산 4개 + 관리 2개 | 이름·내용 그대로 | |

- `명령`은 Pi가 이름으로 찾으므로 **이름을 바꾸지 않는다** → 탭 이름은 `명령` 그대로, 순서만 6번째. (이모지를 붙이고 싶으면 Code.gs `CMD_SHEET`와 Pi를 같이 고쳐야 함 — 하지 않는다.)
- `안내`·`농막_기기`는 웹앱 주소·IP·MAC이 있어 **숨긴다**(삭제·수정은 하지 않음. `안내` A14는 Code.gs가 계속 씀).
- 숨긴 탭도 편집자는 "숨겨진 시트 보기"로 언제든 연다. 지우는 것은 없다.

## 3. 보는 탭의 공통 규칙

| 항목 | 규칙 |
|---|---|
| 1행 | 탭 한 줄 설명 + "기준 시각"(예: `기준 11-16 12:21 · 1시간마다 갱신`) |
| 차트 제목 | **무엇 · 기간 · 단위** — 예: `온도 · 최근 5일 · °C`, `히터 전력량 · 날짜별 · kWh` |
| 시간축 | 시간별은 `11-16(월) 08시`, 날짜별은 `11-16(월)`. 연도는 축에 쓰지 않음 |
| 단위 | 온도 °C 소수 1자리, 습도 % 정수, 전력 kWh 소수 1자리, 풍속 m/s |
| **색(모든 차트 같게)** | 부여 관측소 **파랑**, 바닥외부(바깥) **초록**, 1층 **빨강**, 다락 **보라**, 히터 kWh **주황 막대**, 강수 **하늘색 막대**, 운량 **회색**, 재실 **검은 점** |
| 범례 | 아래쪽. 이름은 `관측소 · 바깥 · 1층 · 다락`으로 통일(`바닥외부`·`내부1층`·`다락(휴대)` 대신) |
| 크기 | 차트 폭 약 900px(휴대폰 가로 화면에서 한 번에 보임), 세로로 쌓기 |
| 경고색 | 빨강 = 위험(동파·끊김), 주황 = 주의(수동 확인), 노랑 = 할 일 |

## 4. 대시보드 옮기기 (`농막_현재` → `🏠 지금`)

`농막_현재` 1~9행은 Pi가 센서 이름으로 행을 찾아 덮어쓰고, 대시보드 수식은 같은 탭의 2~4행을 읽는다. 그래서 그냥 잘라 옮기면 참조가 깨진다.
1. `농막_현재`를 **복제**해 `🏠 지금`을 만든다(수식·서식 그대로).
2. 새 탭 1~9행은 값 대신 **거울 수식**으로 바꾼다: `A1:E9 = {'농막_현재'!A1:E9}`, H열(배터리 예상)도 같은 방식. **F·G열(SSID·IP)은 비운다**(보는 탭에 주소를 두지 않음).
3. 1~9행은 그룹으로 접어 둔다(대시보드가 10행부터 바로 보이게).
4. 원래 `농막_현재` 10~68행은 지우지 않고 그대로 둔 채 탭만 숨긴다(되돌리기 쉬움). 안정되면 나중에 정리.

## 5. 🔥 난방 탭 (새로)

원자료 `농막_시간요약`(시각·모드·히터 kWh·가동 분·평균 W·1층/다락/외기 온습도·선풍기 분)을 수식으로 집계한다.
- 표(숨긴 열 아님, 차트 아래): 날짜 · 히터 kWh · 가동 시간 · 1층 평균 · 다락 평균 · 바깥 평균 · 재실 여부.
- 차트 1: **날짜별 히터 kWh(주황 막대) + 바깥 평균(초록 선)** — 추운 날 전기를 얼마나 쓰는지.
- 차트 2: **최근 7일 시간별 kWh(막대) + 1층·다락(선)** — 언제 돌았는지.
- 이번 달 합계 kWh와 대략 요금(단가는 설정 칸 하나, 기본값만 넣고 사용자가 고침).

## 7. 정할 것 (사용자)

1. "사용자들"이 누구인가 — 편집 권한 가족이면 이 설계로 충분. **보기만 하는 사람**이 있으면 시트 공유는 "뷰어"로 하고, 숨긴 탭은 뷰어도 메뉴로 열 수 있으니(보호 아님) 민감한 `안내`·`농막_기기`는 **별도 비공개 시트로 옮기는 것**을 검토.
2. 탭 이름(이모지 포함 여부), 🔥 난방 탭 전기 단가.
3. 휴대폰에서 더 앱처럼 보고 싶으면 이후 Looker Studio(무료) 보고서로 같은 그래프를 따로 만드는 선택지가 있다(시트는 그대로 원자료).
