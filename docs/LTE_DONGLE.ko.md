# LTE 동글 Huawei E3372h-607 — 개통·시험 기록 (2026-11-13, 집 PC)

> 농막 상시 인터넷용 LTE USB 동글을 집 윈도우 PC에 꽂아 두 유심(KT망 100 GB·6 GB)으로 시험한 기록과 현장 절차.
> 비밀값(유심 번호·전화번호·문자 내용)은 쓰지 않는다. APN은 통신사 공개값이다.
> 관련: 계획 [NETWORK_MIGRATION.md](../NETWORK_MIGRATION.md) §5, 데이터 감시 [TELEGRAM.ko.md](TELEGRAM.ko.md) "데이터 사용량 감시"(`notify/data_watch.py`).

## ⭐ 안테나가 필요한가 — 현장 검사법 (농막 도착하면 먼저)

> **결론(집 시험)**: 도시 집에서는 안테나 없이도 지장 없었다. 농막은 시골이라 기지국이 멀어 더 약할 수 있으니 **현장에서 재 보기 전까지는 안테나를 단다.** 안테나를 달면 신호가 약 12~14 dB 좋아졌다(여유 = 날씨·계절에도 안 끊김).

**검사 (5분)**
```
python3 scripts/lte_signal_check.py 60 안테나      # 안테나 단 채로 1분
python3 scripts/lte_signal_check.py 60 무안테나    # 안테나 빼고 1분
```
동글이 꽂힌 기기(Pi·PC)나 같은 네트워크에서 실행한다. 관리 화면 대신 Home → 신호 막대, 또는 System → Device Information의 RSRP·SINR를 눈으로 봐도 된다.

**판정 기준 — 안테나를 뺀 상태의 1분 중앙값으로**

| RSRP | 판정 |
|---|---|
| **−100 dBm 이상** | ✅ 안테나 없이 써도 됨 |
| **−100 ~ −105 dBm** | ⚠ 쓸 수는 있지만 여유가 없음 → **안테나 권장** |
| **−105 dBm 미만** | ❌ **안테나 필수**. 그래도 약하면 창가·높은 곳으로 옮기고, 그래도 −110 아래면 더 큰 외장 안테나 |

- 아래 중 하나라도 있으면 **한 단계 더 엄하게** 본다: SINR 중앙값 **−3 dB 미만**, 측정 중 **연결 끊김**, 1분 사이 **기지국(Cell ID)이 바뀜**.
- 안테나 없이 "✅"여도 **하루 동안 끊김이 없는지** 확인한 뒤에 뺀다(무인 농막은 한 번 끊기면 일주일을 모름).
- 집 측정 예: 안테나 없음 RSRP −99 / SINR −1(경계), 안테나 있음 RSRP −85~−87 / SINR −1~−2 → 도구 판정 ✅.

## 4. 알아낸 것

1. **유심을 새로 넣으면 첫 등록에 동글 재시작이 필요했다**(두 유심 모두). 현장 절차와 자동 복구에 반영.
2. **APN 프로필이 비어 있으면 데이터가 안 붙는다.** KT망은 `lte.ktfwing.com`. 프로필은 동글에 저장돼 유심을 바꾸거나 Mango·Pi로 옮겨도 유지된다.
3. **경로가 둘이면 조용히 넘어간다.** PC의 Wi-Fi가 끊기자 윈도우가 기본 경로를 LTE로 바꿔 이메일·배경 통신 등 27 MB가 LTE로 나갔다. 경로 우선순위는 Wi-Fi 50, LTE 75. → 집 PC는 시험 뒤 동글을 뽑거나 "종량제 연결"로 지정. 농막은 데이터 감시 필수.
4. microSD 슬롯은 USB 메모리 기능일 뿐 인터넷과 무관. 농막에선 끼우지 않는다.
5. 관리 API(`/api/webserver/SesTokInfo`로 세션·토큰 → `/api/monitoring/status`, `/api/net/current-plmn`, `/api/device/signal`, `/api/net/plmn-list`, `/api/dialup/profiles`, `/api/dialup/dial`, `/api/device/control`)로 상태 읽기·재시작·APN 설정을 모두 할 수 있다. 응답은 XML. 연결 상태 901=연결, 902=끊김. 서비스 상태 2=정상, 1=제한.

## 5. 현장 절차

**농막 도착**
1. 유심 A(100 GB)를 동글을 뽑은 상태에서 넣는다(방향 확인).
2. 외장 안테나 2개를 달고, 창가·높은 곳에 둔다.
3. Mango(또는 Pi)에 꽂고 2분 기다려 **하늘색 켜짐** 확인. 녹색 깜빡이면 한 번 뽑았다 다시 꽂는다.
4. 신호를 잰다: RSRP가 −105 dBm보다 약하면 위치를 옮기거나 더 큰 외장 안테나 검토.

**떠나기 전(유심 B로 바꿀 때)**
1. 동글을 뽑고 유심 B(6 GB)로 교체 → 다시 꽂고 2분 → 하늘색 확인(안 되면 재꽂기).
2. **폰 LTE로 바깥에서 확인**: 시트 현재값이 갱신되는지, 또는 Tailscale로 Pi 접속. 불빛만 믿지 않는다.
3. 데이터 감시(`data_watch`)의 `limit_gb`를 유심에 맞춘다: 유심 A면 100(또는 경보만), 유심 B면 6.

## 6. 남은 일

- Mango 도착 → OpenWrt에서 동글을 WAN으로(cdc_ether), 고정 주소, Pi 연결.
- **자동 복구**: 인터넷이 몇 분 이상 끊기면 동글 재시작(`/api/device/control`), 그래도 안 되면 USB 전원 재인가. 유심 교체 뒤 첫 등록 실패도 사람 없이 풀린다.
- 6 GB 소진 뒤 동작(감속인지 차단인지) 요금제 조건 확인.
- 2027-05: 유심 A 조건 종료 전 사용량 기록을 보고 회선 결정.

## 7. 관리 화면 정보 (System → Device Information 등)

- **공개 금지**: IMEI(동글 고유번호), IMSI(가입자번호), ICCID(유심 카드번호), My number(전화번호). 문서·저장소·대화방에 올리지 않는다.
- **WAN IP가 `10.`으로 시작** → 통신사 내부 공유 주소(CGNAT). 바깥에서 농막으로 바로 못 들어온다 → 원격 접속은 Tailscale. 동글의 포트 포워딩(Virtual Server)·DMZ는 소용없다.
- **Cell ID / eNB / PCI**: 붙은 KT 기지국 번호. 농막에서 신호가 불안정할 때 기지국이 자꾸 바뀌는지 본다.
- **NAT 설정은 Cone 유지**: Tailscale이 기기끼리 직접 연결하기 쉬움(Symmetric이면 중계 서버를 거쳐 느려짐). 주소 변환이 통신사→동글→Mango 세 겹이어도 일반 사용·Tailscale엔 문제없음.
- **Wi-Fi AP 아님**: 동글은 USB로 꽂힌 기기 하나에만 인터넷을 주는 작은 공유기다. Shelly·Home Mini·Qingping은 Mango(또는 Pi)가 뿌리는 Wi-Fi에 붙는다.
- **네트워크 설정은 Auto 유지**(LTE 우선, 안 되면 3G; 전 대역). 시골에서 LTE↔3G를 오가며 끊기면 LTE only, 대역이 흔들리면 B8(900 MHz) 고정을 검토.
- **APN 프로필**(KT-LTE, `lte.ktfwing.com`, IPv4)은 지우거나 바꾸지 않는다. 지우면 데이터가 끊긴다.
- **USSD(*100#)**: 해외 선불 잔액 조회용. 국내 통신사는 대부분 지원 안 함 → 남은 데이터는 통신사 앱, 동글 Statistics, `data_watch` 텔레그램 경보로 본다.
- **관리 비밀번호**: 지금은 로그인 없이 열린다(같은 Wi-Fi의 누구나 APN 삭제·재시작 가능). 농막 설치 때 걸되, `data_watch`·자동 재시작·`lte_signal_check`가 로그인하도록 함께 고친다.
