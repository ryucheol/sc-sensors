# 동지집 대시보드 (구글 시트 `농막_현재` 탭)

작성: 2026-11-11 · 시트:「동지집 기온·습도 기록」 · 자동 갱신 설계는 [KMA_SHEET_PUSH.ko.md](KMA_SHEET_PUSH.ko.md)

휴대폰으로 시트를 열었을 때 한 화면에서 "지금 농막 상태, 오늘 밤 서리·동파, 며칠 뒤 날씨, 해야 할 일"을 보려고 만든 수식 대시보드다. 값을 직접 쓰지 않고 다른 탭을 읽기만 하므로, 원자료 탭이 갱신되면 저절로 바뀐다(시트 재계산 주기: 1시간).

## 1. 위치와 Pi와의 경계

| 범위 | 쓰는 쪽 | 내용 |
|---|---|---|
| `농막_현재` 1행 | Code.gs | 머리글 (센서·온도·습도·배터리·갱신시각·SSID·IP·배터리 예상) |
| 2~4행 | Pi → Code.gs `_postCurrent`, 배터리 추세 | 센서 3개 현재값. **센서 이름으로 행을 찾아 덮어씀** |
| 5~9행 | 비움 | |
| **10~68행, A~G열** | 수식(사람이 편집) | 대시보드 |

- Code.gs는 A열을 위에서부터 읽어 센서 이름을 찾는다(`names.indexOf`). 대시보드에도 "다락"·"바닥외부" 글자가 있지만 2~4행이 먼저 걸리므로 센서 값은 정상 위치에 쓰인다.
- 센서를 추가하면 새 행이 `getLastRow()+1`(대시보드 아래)에 붙는다. 센서 추가 계획이 없어서 이 배치로 확정(2026-11-11).
- 배터리 예상 문구는 H열에만 쓰이고, 대시보드는 A~G열이라 겹치지 않는다.

## 3. 판정 규칙

### 3-1. 텃밭 보정 (관측소급 예보 → 텃밭 최저)

| 밤 조건 (18~09시) | 보정 |
|---|---|
| 맑음 비율 ≥ 50% **그리고** 평균 풍속 ≤ 1.5 m/s | −3℃ |
| 맑음 비율 ≥ 25% | −2℃ |
| 그 밖(흐림·바람) | −1℃ |

근거: 2026-11-07·08·10 서리 관측(맑고 잔잔한 밤 마당이 관측소보다 2~4℃ 낮음). 관측이 쌓이면 다시 맞춘다.

### 3-2. 서리·동파 등급

| 항목 | 기준 | 표시 |
|---|---|---|
| 서리 | 텃밭 예상 최저 ≤ −2 / ≤ 0 / ≤ 2 / 그 위 | 높음(된서리) / 있음 / 약간 / 없음 |
| 동파 | 관측소급 최저 ≤ −10 | 높음: 실내 배관 퇴수 검토 |
| | ≤ −5 | 주의: 부동전 보온 |
| | 텃밭 최저 ≤ −4 | 바깥 호스·노출 배관 주의 |

### 3-3. ⑦ 할 일 문구

| 행 | 조건 | 문구 |
|---|---|---|
| 60 | 오늘 밤 텃밭 예상 최저 ≤ 0 | 오늘 밤 서리: 노지 작물·분재 덮기 |
| 61 | 3일 안 관측소급 최저 ≤ −5 | 부동전 보온·노출 배관 점검 |
| 62 | 3일+중기 최저 ≤ −10 | 한파: 오래 비울 거면 실내 배관 퇴수 |
| 63 | 3일·중기 강수확률 ≥ 60% 인 날 | 비 예보(날짜): 창·데크·바깥 물건 정리 |
| 64 | 비어 있는데 마지막 명령이 난방·취침 | 명령 탭에 동파 입력 |
| 65 | Pi 갱신이 1시간 넘게 끊김 | 부재 중 핫스팟 꺼짐이면 정상, 체류 중이면 확인 |
| 66 | 센서 배터리 예상 소진 60일 이내 | 배터리 교체 준비 |
| 67 | 7일 안 최저 또는 오늘 밤 ≤ −2 | **배수구 P트랩 PG 부동액** (아래) |
| 68 | 위가 모두 비었을 때 | 특이사항 없음 |

**P트랩 PG 부동액 규칙** (50mm P트랩 U자에 물 약 0.3~0.4L가 고여 있어 부은 양이 희석됨)

| 상황 | 문구 |
|---|---|
| 비어 있음 | 다음에 떠날 때 두 컵(0.5L)을 천천히 부어 고인 물 밀어내기 (이미 부었으면 무시) |
| 체류 중, 오늘 밤 ≤ −13 | 두 컵(0.5L) — 한 컵은 −13℃까지만 견딤 |
| 체류 중, 오늘 밤 ≤ −2 | 한 컵(0.25L), 떠날 때는 두 컵 |
| 체류 중, 7일 안 ≤ −2 | 떠날 때 두 컵 |

농도: 한 컵 → 약 30%, 약 −13℃까지 / 두 컵 → 약 45% 이상, 약 −25℃까지. 부여 관측 최저 기록 −22℃.

## 4. 원자료 탭 형식 (대시보드가 기대하는 것)

| 탭 | 범위·형식 |
|---|---|
| `동지집_예보` | A1 설명, A2 머리글, **A3:G83 81행**: A 날짜시각(값), B 기온, C 습도, D 강수확률, E 강수량, F 하늘(맑음·구름많음·흐림·비…), G 풍속. 오늘 00시부터 시작 |
| `부여_시간별` | A 날짜시각, B 기온, C 습도, D 강수, E 운량. 끝에 추가만 (`MATCH(9^99,A:A)`로 마지막 행) |
| `중기예보` | A1 설명(발표시각 `yyyy-MM-dd HH:mm` 포함), A2 머리글, **A3:H9 7행**: 날짜, 오전·오후 하늘, 오전·오후 강수확률, 최저, 최고, 비고 |
| `재실기록` | A 도착, B 출발(빈칸=체류 중). 마지막 행 = `COUNTA(A:A)` |
| `명령` | A 명령, D 결과, E 입력시각. 마지막 행 = `COUNTA(A:A)` |

## 5. 주의

- 이 탭의 기본 셀 서식이 날짜라서, 대시보드 숫자 칸은 숫자 서식(`0.0`, 강수확률 `0`)을 따로 지정했다. 칸을 옮기거나 새로 만들면 서식부터 확인할 것.
- 수식의 `LET` 변수 이름이 셀 주소처럼 보이면(`m7` 등) `#NAME?`이 난다.
- 텍스트와 숫자 비교(`"">=60`)는 참이 되므로, 빈칸을 먼저 걸러야 한다(⑦ 63행).
- 중기 기온 지점 `11C20501`은 부여로 추정해 쓰는 중(미확인).
